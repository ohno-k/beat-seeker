# 当たり配置の学習

当たり配置ランキング（譜面分析ページ）の評価 `frontend/src/utils/randomEval.ts` は、減点の形（皿と同時なのに逆の手、割れない、片手の速い移動 …）ごとの該当ノーツ数を足して並びを順位付けしている。
形ごとの係数 `frontend/src/utils/randomWeights.ts` を手で決めず、次の 2 つの正解データから学習する。学習前は全部 1（係数無し）。

| 正解データ | 集め方 | 使い方 |
|---|---|---|
| 「どっちが押しやすい？」の回答 | 管理者の比較画面 `/admin/random-compare`（サイドバーの「どっちが押しやすい？」） | 見せた区間の減点を数え直して、2 つの並びの比較として使う |
| オプション投票（弱い正解） | 既存の譜面ごとの投票（`option_votes`） | 正規と MIRROR の票の割合を「正規の方が押しやすい確率」として、譜面全体の比較に使う（重みは回答より軽い） |

## 1. 回答する

`/admin/random-compare` を開くと、同じ数小節を 2 通りの並びで描いた画像が左右に出る（下が始まり、時間に比例した一定速度）。

- 押しやすい方の画像をクリック（または ← / →）
- 同じくらい: ↓ 、判断できない: S 、直前の取り消し: Z
- レベル帯と区間の長さ（2 / 4 / 8 小節）を選べる。並びの番号と今の評価は、答えに影響しないよう既定では隠してある

出題は 3 通りを混ぜている（`utils/randomPairQuestion.ts`）: 今の評価では僅差なのに減点の内訳が違う組（5 割。一番学習に効く）、無作為な組（3 割）、正規か MIRROR と無作為な並び（2 割）。
区間は 2 つの並びの差が大きい所を選び、左右はくじで入れ替える。回答は `random_pair_votes` に「どの譜面のどの区間をどの並びで見せたか」で残すので、評価の数え方を変えても学び直せる。

目安は 1,000 件。合成データでの試験では、回答 600 件で正解率が 72% → 75% に上がり、3,000 件で隠れた本当の係数をほぼ取り戻せた。

## 2. 学習する

```bash
# 画面の「学習用データを書き出す」で保存した JSON から
node scripts/fit-random-weights.mts random-pairs-2026-10-09.json --write

# API から直接（自動実行用）。トークンは管理者の個人 API トークン（プロフィールの外部連携で発行。期限なしにできる）
BEAT_SEEKER_TOKEN=bs_live_... node scripts/fit-random-weights.mts --write
```

- 再生データは `--playback=<jsonl>`（`build-random-ranking.mts` の入力と同じ形）か、無ければ `--api`（既定 https://beat-seeker.com）から取って `data/random-learning/playback-cache.jsonl` に貯める
- モデル: P(左が押しやすい) = σ(Σ β_k × (右の減点_k − 左の減点_k) / 規模)。β_k ≥ 0、「全部同じ係数」へ引き戻す罰則つき（強さ λ は交差検証で選ぶ）
- 検証: 譜面ごとに 5 分割した交差検証で、学習に使っていない回答の正解率と対数損失を「全部同じ係数」と比べる
- `--write` でも、回答（同じくらい・スキップ以外）が 100 件以上あり、学習後の方が正解率・対数損失とも良いときだけ書き換える（`--force` で強制）
- 結果の詳細は `data/random-learning/report-<日時>.json`

回答が 0 件でも、オプション投票と今のランキング（`summary.json`）の一致は出る（正規と MIRROR の票の多い方を当てた割合、正規・MIRROR 派の譜面ほど正規・MIRROR の順位が良いかの AUC）。今の評価の物差しとして使える。

## 3. ランキングを作り直す

係数を書き換えたら、ランキングのデータを作り直してデプロイする。

```bash
node scripts/build-random-ranking.mts <再生データ.jsonl>
```

## 自動で回す

毎晩などに「書き出し → 学習 → 良くなったときだけ係数を更新 → ランキングを作り直す」を回せば、回答が増えるたびに精度が上がる。

```bash
BEAT_SEEKER_TOKEN=bs_live_... node scripts/fit-random-weights.mts --write \
  && git diff --quiet frontend/src/utils/randomWeights.ts \
  || node scripts/build-random-ranking.mts <再生データ.jsonl>
```
