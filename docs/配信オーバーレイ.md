# 配信オーバーレイ（単曲ティアの目盛り・リザルト表示）

アーケードの IIDX をキャプチャボードで配信しているときに、OBS に重ねて使うページ。

- **プレー中**: スコアグラフの横に、単曲ティアの拡大目盛りを出す。YOU の EX を読み、届いた線を黄色にする。
- **リザルト**: プレー後の暗転でリザルト画面の中央に、EX スコア・前回ベストとの差・DJ LEVEL・BEAT-PT・単曲ティアの変化を出す。

ページは `https://beat-seeker.com/obs/score-overlay`。**beat-seeker へのログインが必要**（リザルトで自分の自己ベストと比べるため）。
管理者はサイドバーの「配信オーバーレイ（試験）」から、録画で試すテストモードを開ける。

## OBS への取り込み方

OBS 28 以降が必要（WebSocket が標準で入っている）。

### 1. OBS の WebSocket を有効にする

1. メニューの「ツール」→「WebSocket サーバー設定」を開く。
2. 「WebSocket サーバーを有効にする」にチェックを入れる。
3. 「認証を有効にする」にチェックを入れ、パスワードを決める。ポートは 4455 のまま。

### 2. キャプチャボードのソース名を控える

ソース一覧に出ているキャプチャボードのソースの名前（例: `映像キャプチャデバイス`）を、一字一句そのまま使う。

### 3. ブラウザソースを追加する

1. ソース一覧の「＋」→「ブラウザ」を追加する。
2. URL に次を入れる。

   ```
   https://beat-seeker.com/obs/score-overlay?source=<ソース名>&password=<パスワード>
   ```

   - ソース名に空白が入る場合は `%20` に置き換える。
3. 幅と高さはキャプチャボードの解像度に合わせる（1080p なら 1920 × 1080）。
4. ソース一覧で、ブラウザソースをキャプチャボードのソースより上に置く。

### 4. ログインする（初回だけ）

OBS のブラウザソースは、普段使っているブラウザとログイン状態を共有しない。
初回はブラウザソースにログイン画面が出るので、次の手順でログインする。

1. ブラウザソースを右クリック →「対話」を開く。
2. 開いた窓の中で IIDX ID とパスワードを入れてログインする。

ログイン情報は OBS の中に残るので、次回からは入力不要。
ログインの期限が切れたときは、もう一度ログイン画面が出る。

### 5. 位置をゲーム画面に合わせる

1. キャプチャボードのソースを右クリック →「変換」→「変換をコピー」。
2. ブラウザソースを右クリック →「変換」→「変換を貼り付け」。

（日本語版 OBS の表記。英語版では Transform → Copy Transform / Paste Transform。）

配信画面でゲーム画面を縮小・移動していても、これで目盛りがグラフの横に重なる。
レイアウトを変えたら、もう一度コピーと貼り付けをする。

### 6. 動作確認

- 曲をプレーすると、プレー画面の間だけ目盛りが出る（選曲画面では出ない）。
- 曲が終わって暗転すると、リザルト画面の中央に成果が出る。次の暗転（選曲画面へ戻る）か次のプレーで消える。それより遅くても、出てから 20 秒で消える。
- 何も出ないときは URL の末尾に `&debug=1` を付ける。左上に接続状態・配置・曲・EX・OCR の結果が出る。

## 自己ベストとの比較

リザルトの「前回ベストとの差・NEW RECORD・ティアの変化・BEAT-PT の増分」は、ログインしたユーザーのスコアと比べる。

- 前回ベストは、ページを開いた時点（OBS 起動時など）のスコア。最後に CSV を取り込んだときの記録になる。
- 配信中に同じ曲をもう一度プレーしたときは、その配信内のベストとも比べる。
- CSV を取り込み直したあとは、ブラウザソースを再読み込みすると新しい記録で比べる。
- **歴代自己ベスト**も出す。今作の記録と、取り込んである前作以前の記録（前作 CSV の取り込み）の高い方を、作品名つきで表示し、今回との差を出す。今回が上回れば「歴代ベスト更新」の札が付く。前作以前を取り込んでいなければ今作の記録だけで比べる。

## URL のパラメータ

| 名前 | 内容 |
|---|---|
| `source` | キャプチャボードのソース名（必須） |
| `password` | obs-websocket のパスワード |
| `host` / `port` | obs-websocket の接続先。既定 `127.0.0.1` / `4455` |
| `interval` | 読み取り間隔（ミリ秒）。既定 250 |
| `debug=1` | 左上に読み取り状況を出す |
| `test=1` | OBS を使わず、録画や画像ファイルを読み込んで試す |
| `rank` / `ex` / `best` / `alltime` | テストモード専用。☆・EX・前回ベスト・過去作ベスト（`alltime=2480:33` の形）を上書きして表示を確認する |

## 注意

- URL に obs-websocket のパスワードが入る。ブラウザソースのプロパティ画面を配信に映さない。
- ログイン画面が出ている間は、それが配信にも映る。初回ログインは配信を始める前に済ませる。
- 単曲ティアの目盛りが出るのは、非公式難易度表に載っている ☆11.0〜13.1 の ANOTHER / LEGGENDARIA。それ以外（Lv10 以下・HYPER・未分類の新曲）は **Rate-PT の目盛り**を出す。左が Rate-PT の点数（1PT〜512PT）、右が MAX からの減点（例 4PT = MAX-145）で、見た目と棒の伸び方は単曲ティアと同じ。
- 目盛りには追加で 3 本の線を重ねる。名前の札は帯の外側に出し、届いたら実線になって ✓ が付く。
  - **自己ベスト**（緑）… 今作の自己ベスト
  - **BEAT TOP100**（オレンジ）… BEAT-PT の上位 100 譜面に入るのに必要な EX（他の譜面の 100 番目を上回る点）。理論値でも入れない譜面と、☆の無い譜面では出さない
  - **RATE TOP100**（水色）… RATE-PT の上位 100 譜面に入るのに必要な EX（ANOTHER / LEGGENDARIA のみ）
  - 自分の記録が 100 譜面に満たないときは、どの点数でも入れるので TOP100 の線は出さない
- プレー中に画面が暗転してリザルトが出てしまっても（グラフ欄の背景の動画の暗転など）、監視は続けていて、8 秒以内に同じプレーの画面へ戻ればリザルトを消してプレーの続きを追う。
- リザルトには SCORE RATE / DJ LEVEL / BEAT-PT / RATE-PT の 4 欄を出す。RATE-PT はサイトと同じく ANOTHER / LEGGENDARIA だけ（HYPER などは「---」で、目盛りも出さない）。単曲ティアの無い譜面は BEAT-PT が「---」になり、単曲ティアの欄の代わりに次の Rate-PT の区切りまでの残りを出す。
- 目盛りの線はブロックの入口（各ブロックの 1）だけ。サブティアはリザルトに出す。
- 1P 側で確認済み。2P 側は左右反転の位置を仮定していて未確認。
- 日本語の曲名は未確認（アーティスト名の日本語は読めている）。

## 仕組み（開発者向け）

- 画面の読み取りは `frontend/src/utils/iidxPlayScreen.ts`。座標は 1920×1080 の実測値で、他の解像度は比例換算。
  - グラフ配置（1P/2P × 遠め/近め × 縦の位置 2 種の 8 通り）は AAA/AA/A の目盛り線で判別する。縦の位置は置き場所ではなくペースメーカーで変わる（ライバルと対戦するとグラフの上に VS 欄が入って縮む）。線は届く前は青、届くと黄色になる。「線の行が上下 5〜7px の行より線の色が多い」ことで判定し、一面の青い BGA や青の多い背景の絵と区別する。
  - EX は 4 桁の 7 セグメント風の数字を、7 つの画の判定矩形の塗りの割合で読む。桁の位置は映像によって左右に 2px ほどずれるので、矩形は角の出っ張り（2・3・5・9）を拾わない幅にしてある。
  - 難易度は曲名パネルの PLAYER 01/02 札の色、曲名とアーティストは tesseract.js（英語のみ・日本語込みの 2 通り）で読み、`utils/overlaySongMatch.ts` で照合する。
- OBS との通信は `frontend/src/utils/obsWebSocket.ts`（obs-websocket v5 の GetSourceScreenshot）。
- 画面本体は `frontend/src/views/ObsScoreOverlayView.vue`。
