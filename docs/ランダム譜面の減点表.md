# ランダム譜面の減点表

RANDOM の配置評価（`frontend/src/utils/randomEval.ts`）で、減点の形ごとの 1 ノーツあたりの重さを軽い順に並べた表。
数え方を変えたときは、この表も合わせて直す。

レーン番号はすべて 1P 換算（2P は左右反転して数える）。

## 全体のルール

- **難所の重みがかかる**：上の値には、そのノーツの前後1秒の密度を譜面内の最大値で割って2乗した値（0〜1）が掛かる。スカスカの区間で起きた減点はほとんど効かない。
- **重複して数える**：1つのノーツが複数の形に当たれば、形ごとに足す（例：割れない＋片手の速い移動＝2）。
- **形ごとの係数はなし**：総合点は上の値（難所の重みつき）の単純な合計で、少ないほど押しやすい並び。
- 同じ重さ（1）の形どうしの並び順に意味はない。
